# 刷题方法

## 知识点

1. 数组 / 字符串 + 双指针、滑动窗口
2. 哈希表
3. 二分查找
4. 栈 / 队列、单调栈
5. 链表（反转、快慢指针、合并）
6. 二叉树（遍历、DFS / BFS）
7. 堆 / Top K
8. 图（BFS / DFS、拓扑排序、并查集）
9. 回溯（子集、排列组合）
10. 动态规划（子序列、背包、打家劫舍、股票问题）
11. 前缀和、贪心
12. 设计题（LRU 缓存这类）

## 题库

### 主线
- **LeetCode Hot 100**：必刷第一遍，覆盖最高频题型
- **NeetCode 150**：按专题分好类，适合系统性补弱项，网站有免费路线图
- **Grind 75 / Blind 75**：时间紧时的浓缩版，和 NeetCode 高度重合

### 冲刺
- **各公司 Tag 题**：LeetCode 按公司筛选的高频题（Google、Meta、Amazon、TikTok 近半年高频），冲刺期主攻目标公司

### 辅助
- **一亩三分地**：看各公司的面经和真题，中文社区北美求职最全，OA 原题经常能搜到
- **LeetCode 周赛**：后期练速度和临场

## 每道题的标准动作（决定成败的部分）

1. **复述 + 问约束**（2 分钟）：n 的范围？是否有序？有无重复？空输入？会不会溢出？
2. **说暴力解 + 复杂度**（30 秒内），不要沉默思考
3. **找瓶颈 → 给优化方向**：哈希？排序？二分？DP？双指针？
4. **先讲方案再写码**，让面试官有机会纠正你
5. **边写边说**，变量命名清晰，不炫技
6. **写完手跑 2 个例子 + 边界**：空、单元素、全相同、极值
7. **主动报复杂度 + follow-up**："如果这是数据流呢？""如果内存放不下呢？"
8. **25 分钟没思路就要提示**，硬撑扣分；沟通本身是评分项
