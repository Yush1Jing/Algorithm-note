# Algorithm Notes

My algorithm and LeetCode study notes, published as a website with MkDocs Material.

## Structure

- `docs/method.md`: study plan, topics, problem sets, interview checklist
- `docs/data-structures/`: data structure basics
- `docs/patterns/`: algorithm patterns and templates
- `docs/problems/`: one page per problem (brute force → bottleneck → optimization)
- `docs/mistakes.md`: mistakes log

## Local preview

```bash
pip install -r requirements.txt
mkdocs serve
```

Every push to `main` rebuilds and publishes the site through GitHub Actions.
